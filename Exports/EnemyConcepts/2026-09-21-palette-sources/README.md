# 맵 전용 일반몹 12종 몸통색 수정

기존 대식세포·B세포·NK세포의 몸통색을 참고해 주황빛/선명한 연어색을 낮추고 회분홍색과 보랏빛 음영으로 수정했습니다. 위산, 혈전 장갑, 공기주머니는 식별할 수 있도록 고유색을 남겼습니다.

- `preview.html`: 12종 변경 전후 비교, 대기/이동/공격/사망 애니메이션 전환.
- 루트의 PNG 12개: 내장 이미지 생성 도구로 기존 애니메이션 시트를 편집한 원본.
- `Before/`: 변경 전 게임 스프라이트와 임포트 설정 백업.
- `prompts.md`: 모든 생성 요청에 사용한 프롬프트와 참조 이미지 설명.
- `meta-before.json`: 수정 전 스프라이트 메타 파일 SHA256.
- 게임 적용 위치: `Assets/_Project/Art/Images/Enemies/BiomeExclusive/`.

원본에서 추출한 기준색: 몸통 #AC7A7D / #BF989B, 그림자 #946B82 / #AA8393, 밝은 부분 #DFBCBC / #EDD6D6, 외곽선 #4A1A48 / #801A34. 생성 결과는 이 팔레트에 가까운 색조이며 모든 픽셀을 해당 색 코드로 강제 치환한 결과는 아닙니다.

각 몬스터의 4가지 동작 × 4프레임, 총 192개 PNG를 교체했습니다. `Tools/BuildBiomeEnemySprites.ps1`로 투명 배경/크로마키를 정리하고 프레임을 분리했습니다. 기존 128×128 크기와 메타 파일을 보존했으며 능력치, 스폰, 공격 방식, 애니메이션 참조는 변경하지 않았습니다.
