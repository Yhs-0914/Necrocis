## 조합 검증 우선순위

- 이중핵/삼중핵 + 광선 기관 + 세포 증식: 발사 수와 실제 단일 보스 피해.
- 삼중핵 + 독성 점막 + 출혈 기관: DOT 갱신/중첩과 최소 피해 문제.
- 외골격 + 생체 장막 + 회복 인자: 회복 가능한 평균 피격량과 무한 생존.
- 금단 성장 + 돌연변이 안구 + 집중 신경: 첫 지역부터 공격력 폭증 여부.
- 혈액 드론 + 장기 촉수 + 감염 숙주: 공격하지 않고 이동만 해도 클리어 가능한지.
- 분열 조직 + 관통 점액 + 기생 폭탄: 이벤트 재귀, 재타격, 연쇄 처리 비용.

3슬롯 조합 전부를 플레이 검증했다는 의미는 아니다. 표준 빌드와 상위 시너지를 먼저 측정하고, 무아이템 대비1.6~2.2배 및 상위 약2.5배 목표를 벗어나면 전체 적 HP를 올리기 전에 해당 시너지를 조정한다.
