- **광선 + 불안정 세포:** 탄속 대신 같은 확률의 피해 보너스 적용. 추가 증식 공격에는 이전 확률 보너스를 중복 누적하지 않는다.

- **기생 폭탄:** 플레이어 위치 대신 처치한 적 위치에서 폭발한다.
