# 회의 요청 적용 — 2026-11-01

플레이어 레벨에 따른 잡몹·엘리트 체력 증가, 아이템 보유 제한 제거, 몬스터 아이템 드랍, 모든 월드 아이템의 3개 중 1개 선택, 난이도별 엘리트 피해, 기본 능력치 아이템 6종을 적용했다.

| 플레이어 레벨 | 잡몹 체력 배율 | 엘리트 체력 배율 |
| --- | --- | --- |
| 1~5 | 1.00 | 1.00 |
| 6~10 | 1.15 | 1.12 |
| 11~15 | 1.30 | 1.24 |
| 16~20 | 1.45 | 1.36 |
| 21~25 | 1.60 | 1.48 |
| 26~30 | 1.75 | 1.60 |

기존 스포너의 마릿수 증가와 같은 5레벨 구간을 쓴다. 지역 진행도·난이도의 체력에 위 배율을 곱한다. 이미 살아 있는 몬스터도 다음 업데이트에 적용하며 남은 체력 비율을 유지한다. 풀에서 재사용할 때 중복 적용하지 않는다. 보스 체력은 이 배율에서 제외한다.

| 처치 대상 | 아이템 드랍 확률 | 지급 방식 |
| --- | --- | --- |
| 잡몹 | 1% | 상자 1개, 3개 중 1개 선택 |
| 엘리트 | 10% | 상자 1개, 3개 중 1개 선택 |
| 지역 보스·최종 보스 | 100% | 전투당 상자 1개, 3개 중 1개 선택 |

새 랜덤 맵 상자를 배치하지 않는다. 이전 세이브의 미수령 상자는 복원한다. 폐 보스 두 몸은 전투 하나로 처리한다. 최종전의 경험치 없는 소환물과 처치 보상을 억제한 개체는 아이템도 드랍하지 않는다. 기존 시작 변이 보상·정해진 처치 수의 회복 드랍은 유지한다.

선택지·위치·수령 여부를 저장한다. 선택 화면을 닫아도 상자는 남으며 다시 접근할 때 선택할 수 있다. 다른 상자에서 이미 획득한 특수 아이템은 새 후보로 교체하되, 여전히 받을 수 있는 후보는 유지한다. 기존 특수 아이템은 중복 불가, 신규 기본 아이템 6종은 중복 누적이어서 후반에도 서로 다른 후보 3개를 제공한다. I 키 인벤토리는 휠·드래그로 전체 보유 목록을 확인한다.

엘리트의 패턴·접촉 피해는 일반 HP 3(하트 1.5칸), 하드 HP 4(하트 2칸)로 통일한다. 지역 진행도에 따라 이 기준 피해가 추가 증가하지 않는다. 피해 감소 아이템과 무적 효과는 이후 적용한다. 공격 간격은 기존 패턴 설정을 사용한다.

| 신규 아이템 | 효과 | 중복 |
| --- | --- | --- |
| 응축 근육 | 공격력 +1 | 누적 |
| 경화 근육 | 공격력 +2 | 누적 |
| 생명 세포 | 최대 HP +1, 획득 시 HP +1 회복 | 누적 |
| 생명 장기 | 최대 HP +2, 획득 시 HP +2 회복 | 누적 |
| 신속 세포 | 공격속도 +5% | 합산 |
| 탄성 섬유 | 이동속도 +0.5 | 누적 |

기본 아이템의 보너스는 획득한 개체별로 관리한다. 하나를 버리면 해당 보너스만 제거하며 저장·불러오기로 중복 적용하거나 추가 회복하지 않는다. HP 1은 하트 반 칸이다.

전체 66종의 현재 성능은 [아이템 표](MEETING_ITEMS_2026-11-01.md)와 [회의용 엑셀](../../outputs/necrocis-meeting-2026-11-01/네크로시스_아이템_성능표.xlsx)에 있다. 엑셀의 회의 메모는 자유롭게 작성할 수 있으며 게임 설정을 직접 변경하지 않는다.

조정 위치: `LevelProgressionConfig`의 Enemy Health by Player Level, 난이도 프로필의 Elites / Fixed Hit Damage, `CampaignRewardRules`의 드랍 확률 상수, `PlayerStatItemCatalog`의 신규 아이템 수치.

## 후속 요청: 레벨업 선택 성장

일반·하드 모두 선택 1회당 다음 수치로 적용한다. 기본 설정과 런타임 자산을 함께 바꾸고, 선택 화면의 퍼센트 능력치에 `%` 단위를 표시했다.

| 능력치 | 선택 1회 상승량 | 적용 |
| --- | --- | --- |
| 공격력 | +1 | 고정 합산 |
| 공격속도 | +20% | 퍼센트 합산 |
| 마력 | +25 | 스킬 피해 배율 +25%p |
| 최대 체력 | +2 | 하트 한 칸 증가·현재 체력도 +2 회복 |
| 이동속도 | +5% | 퍼센트 합산 |
| 공격 사거리 | +10% | 퍼센트 합산 |

전투 중 공격력 5에서 +1은 평타 피해 +20%다. 이를 비교 기준으로 공속·마력·생존을 체감할 수 있게 올리고, 이동속도·사거리는 전투 거리에 미치는 영향을 고려해 낮은 비율로 정했다. 모든 레벨과 조합에서 동일한 효과를 보장하는 환산식은 아니며 실제 플레이로 조정할 시작 수치다.

현재 선택 화면과 기존 선택 화면이 모두 활성 난이도의 설정을 읽는다. 이미 저장된 성장 보너스는 원래 획득한 수치로 복원하고, 새 선택부터 변경한 수치를 사용한다. 생체 도박은 변경한 상승량에 기존 0/1/2배 규칙을 적용한다.

검증: 런타임·에디터 C# 빌드, 직렬화 자산 196개 검사, 실제 게임 C# 계산식 2,924개 검사, 격리된 Unity 프로젝트 106개 검사. Unity 검사에는 실제 레벨업 화면의 적용 함수, 6개 능력치의 반복 선택, 한 칸 회복, 성장 저장, 기존 화면 경로와 아이템·몬스터 검사를 포함한다. 엑셀은 필터·헤더 고정·수식·렌더링을 확인했다. 원본 프로젝트의 실제 전투 장면, 물리 드랍 수집과 UI의 플레이 체감은 별도 플레이 확인 대상이다.
