# 초반 템포 개선 — 2026-10-26

기존 2시간 설계의 초반 해금 일정보다 이 문서의 적용값을 우선한다.

## 적용

- Normal/Hard: 직업 선택 및 E 해금 Lv5, R 해금 Lv10. 직업별 성장 선택 시작 설정은 Lv6이나 현재 주력 성장 UI는 이 후보 생성 경로를 사용하지 않는다. [전체 재점검](REVIEW_2026-10-26.md)의 UI 분석 참고.
- 요구 경험치 곡선은 유지한다. 일반 처치 보상 기준 직업 선택까지 누적 EXP 240, R까지 누적 EXP 990이다. 실제 도달 시간은 플레이 검증 대상이다.
- 직업 선택 후 현재 필드에서 플레이어가 서 있는 이동 가능한 타일에 시작 변이 상자를 추가한다. 기존 지역 상자 3개는 유지한다.
- 전사: 근육 경련 / 혈액 드론 / 전기 신경망. 궁수·마법사: 이중핵 / 관통 점액 / 폭발 혈구. 이미 소유한 후보는 제외하고 지정된 예비 후보로 보충한다.
- 시작 보상 ID는 캠페인 전체에서 하나다. 후보·지역·좌표·수령 여부를 기존 월드 보상 저장 경로로 보존한다. 미수령 상자는 원래 지역에 남는다. 기존 세이브에도 시작 보상이 없으면 한 번 제공한다.
- 직업을 고르지 않은 기존 고레벨 세이브도 선택을 기다리며 경험치를 보관한다. 복원 시 이전 세션 직업이 아닌 저장된 직업을 기준으로 경험치를 처리한다.
- 저장 복원 중에는 직업 선택창을 열지 않고, 복원 완료 후 다시 판단한다.

## 레벨별 잡몹 스포너

잡몹 스포너 하나가 유지하는 목표 마릿수는 플레이어 레벨에 따라 다음 범위에서 정한다. 전체 맵의 몹 수가 아니라 스포너별 동시 생존 목표다.

| 플레이어 레벨 | 스포너당 잡몹 수 |
| --- | --- |
| 1~5 | 1~2 |
| 6~10 | 2~3 |
| 11~15 | 3~4 |
| 16~20 | 4~5 |
| 21~25 | 5~6 |
| 26~30 | 6~7 |

- 같은 구간에서는 스포너별 무작위 목표를 유지하며 매 프레임·재생성마다 다시 추첨하지 않는다. 다음 구간 진입 시 목표를 갱신한다.
- 새로 불러온 스포너도 현재 레벨을 사용한다. 추가 생성에는 기존 거리·재생성 대기·화면 밖 조건을 적용한다.
- Normal/Hard의 `LevelProgressionConfig`에서 `Normal Enemy Spawner Population`의 레벨 간격과 첫 구간 최소/최대 수를 조정할 수 있다. 구간마다 최소·최대가 각각 1씩 증가한다.
- 잡몹 수는 기존 개별 규칙의 `maxAlive` 및 난이도/지역의 양수 `enemyMaxAlive` 배율 대신 이 범위를 사용한다. `maxAlive` 또는 배율이 0 이하이면 비활성화하는 동작은 유지한다. 스포너 배치 밀도와 엘리트·보스의 수는 이 규칙에 포함하지 않는다.

## 검증 및 범위

- 자산 및 실제 C# 계산 검사는 기존 세이브 직업 미선택 복원, Lv5 직업/E, Lv10 R, 직업별 시작 후보와 중복 제외를 포함한다.
- 런타임 C# 컴파일 오류 0개. Unity 엔진의 실제 UI·물리·씬 전환 플레이 검증은 별도다.
- 시작 변이 보상은 Lv5 직업 선택 후 필드에서 제공한다. 시간 경과에 따른 자동 지급은 없다.
- 맵 축소, 보스 체력, 근접 공격 간격, 반복 엘리트 주기, 새 스킬 변형은 이번에 변경하지 않았다. 초반 해금과 아이템 제공의 효과를 먼저 비교한다.

## 플레이 확인

1. 새 게임: Lv4까지 직업 선택/E가 잠겨 있고 Lv5에 직업을 선택하면 E 사용 가능, R은 Lv10에 해금.
2. 장·간·폐·위 중 어디부터 입장해도 직업 선택 이후 시작 상자를 만나고 직업에 맞는 후보 중 하나를 선택.
3. 선택 전후 저장·재진입 시 같은 보상이 복원되고 수령 후에는 재생성되지 않음.
4. 직업 없는 기존 Lv2~10 세이브와 직업 있는 세이브를 각각 이어하기. 복원 중 선택창이 개입하지 않고 기존 직업 유지.
5. 같은 직업·맵 시드로 20분 비교: 첫 아이템, R 해금, 보스 도달, 보상 없는 최대 공백 및 지루해진 시점 기록.
