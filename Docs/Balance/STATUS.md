# 밸런스 문서 구현 상태

초반 템포 후속 변경: 직업/E Lv5, R Lv10 및 캠페인당 시작 변이 보상을 적용했다. 기존 해금 시간 목표보다 [EARLY_PACING.md](EARLY_PACING.md)를 우선한다.

최신 전체 재점검: [REVIEW_2026-10-26.md](REVIEW_2026-10-26.md). **개선 제안은 아직 미적용**이다. 실제 성장 UI에서 직업별 후보가 보장되지 않는 점, 선택 대기의 저장/복원 누락, 중독·출혈 갱신 문제를 추가 확인했다. 아래 “적용”은 모든 동작 검증이 끝났다는 뜻이 아니다.

2026-10-26 추가 요청까지 반영한 기준. 원래 조사표를 적용 전 기록으로 남겼기 때문에 “최초 시험안”, “미적용” 같은 과거 표현과 현재 상태를 혼동하지 않도록 이 표를 우선한다.

문서에 구체적인 수치나 동작으로 정한 구현 항목은 두 차례에 걸쳐 반영했다. **맵15~20분, 첫 아이템3~5분, 최종Lv28~30, 직업 편차±15%, 전체110~130분은 플레이 결과로 맞춰야 하는 목표**다. 이를 검증했다고 표시하거나 강제 대기·이동 잠금으로 보장하지 않았다.

계산 검사와 저장 자산 검사는 통과했고, Unity 인게임·물리·코루틴·새 보상 UI 검사는 이전에 확인한 라이선스 제약으로 아직 실행하지 못했다. 추가 코드 튜닝의 판단 근거는 새로 남는 플레이 기록과 실제 Unity 플레이 결과다.

최신 재점검에서 C# 계산 검사1,687개, 저장 자산 검사174개 통과. 추가 탐침에서 선택 대기 복원 문제를 확인했으며 기존 검사는 이를 보장하지 않는다. 이전 구현 단계의 런타임·에디터 컴파일 오류는0개였고, 이번 문서 작업에서 플레이를 실행하지 않았다. 보스의 CC는 일반 이동에 적용하며 이미 시작된 위험 패턴이나 붕괴 제한 시간을 취소·연장하지 않는다.

플레이 기록은 세이브의 `balanceMetrics`에 누적된다. Unity 플레이 중 `Necrocis > Balance > Export Current Balance Report`를 누르면 `Logs/CampaignBalance/current-play-report.json`으로 내보낸다. 활성 플레이 시간과 UI 일시정지를 포함하는 세션 시간을 구분한다. 창을 다른 앱으로 전환한 시간은 세션 시간에서 제외한다.

기존 세이브에 없는 상자 이력은 최초 로드 이후부터 기록한다. 업데이트 전 이미 획득했던 상자를 소급 판별하거나 기존 성장값을 강제로 재계산하지 않는다.
