## 프로젝트에서 확인한 기준

- [프로젝트 소개](../../../../../README.md): 인체 장기 배경의 Unity 2.5D 액션 게임, 장·간·위·폐 탐험.
- [장 적 스폰 설정](../../../Data/BiomeConfigs/IntestineEnemySpawnConfig.asset): 일반 적 Macrophage / NKCell / BCell 3종, 엘리트 Granuloma / Antibody 2종 등록.
- [간](../../../Data/BiomeConfigs/LiverEnemySpawnConfig.asset), [위](../../../Data/BiomeConfigs/StomachEnemySpawnConfig.asset), [폐](../../../Data/BiomeConfigs/LungEnemySpawnConfig.asset)의 별도 EnemySpawnConfig는 확인 시점에 `enemySpawnRules: []`였다. 이는 해당 에셋의 상태이며, 모든 런타임 경로에서 적이 전혀 없다는 뜻은 아니다.
- 기존 대식세포·NK세포·전사 플레이어와 바이옴별 보스 스프라이트를 직접 확인했다. 작은 도트, 진한 외곽선, 단순한 얼굴과 장기 형태를 시각 기준으로 사용했다.
- 보스 아트에서 장의 올리브/충란, 간의 보라색 막, 위의 분홍색/큰 입, 폐의 노란색/Y자 기관을 가져왔다.
- [간 보스 패턴](../../../Scripts/Gameplay/Enemies/Bosses/LiverBossPattern.cs)의 혈액 폭탄·회복, [폐 보스 패턴](../../../Scripts/Gameplay/Enemies/Bosses/LungBossPattern.cs)의 바람·가스·급강하를 잔몹 수준의 단순한 동작으로 해석했다.

## 아트와 판독 규칙

- 지형 위에 서는 2D 빌보드 캐릭터. 기본은 정면 또는 약한 3/4 시점이며 발/지면 접점이 읽혀야 한다.
- 기존 작은 스프라이트에 맞춰 제작 시 본체 24–48px 범위에서 먼저 실루엣을 검토한다. 참고 시트의 확대 묘사를 그대로 축소하면 디테일이 뭉칠 수 있으므로 재도트화가 필요하다.
- 기본 크기는 플레이어 높이의 0.7–1.2배, 방어형과 소환형도 1.4배 이내를 시작점으로 제안한다. 이미지 속 예고/공격 칸의 작은 플레이어는 도해용이며 정확한 게임 배율이 아니다.
- 공격 기관은 하나를 중심으로 잡는다: 갈고리, 점액낭, 채찍, 알주머니, 방패막, 담즙낭, 혈전, 혈관, 볼주머니, 구르는 몸, 집게, 깔때기, 폐포, 분사구, 활공막, 포낭.
- 점선/황색 바닥 표식은 예고, 실선/실제 이펙트는 공격이다. 색뿐 아니라 팽창·기울임·조준·그림자와 같은 형태 변화로도 구분한다.
- 타깃 위치와 방향은 예고 초반에 고정하고, 공격 직전에 급회전하거나 플레이어를 끝까지 추적하지 않는다.
- 시트는 콘셉트 검토용 PNG다. 투명 배경, 프레임 분할, 피벗, 방향별 애니메이션을 갖춘 즉시 사용 가능한 게임 스프라이트는 아니다.

## 제작 우선순위와 첫 검토

첫 제작 후보는 바이옴당 2종씩 제안한다.

| 장 | 간 | 위 | 폐 |
| --- | --- | --- | --- |
| 갈고리 유충 + 점액 달팽이 | 응고 방패충 + 재생 성상충 | 위석 굴림충 + 유문 집게 | 폐포 풀무충 + 흉막 활공충 |

같은 바이옴 안에서도 실루엣과 대응 방식이 서로 달라지는 조합이다. 나머지 8종도 본 문서와 이미지에 포함된 완성된 콘셉트 후보이며, 이 순서는 실제 구현 범위를 확정한 것이 아니다.

제작 시 공통 애니메이션 시작안: 대기 4프레임 / 이동 4–6프레임 / 예고 3–4프레임 / 공격 3–5프레임 / 회복 2–3프레임 / 피격 1–2프레임 / 사망 4프레임. 고정형은 이동 대신 뿌리 흔들림을 사용하고, 발사/바람/장판 이펙트는 본체와 분리한다. 프레임 수는 모두 제안이다.

플레이테스트 체크리스트:

- 실제 카메라 크기에서 색을 빼도 실루엣으로 잔몹을 구분할 수 있는가.
- 첫 조우에서 예고 동작을 보고 공격 방향과 범위를 이해할 수 있는가.
- 예고가 끝난 뒤에도 공격 판정이 표식을 벗어나지 않는가.
- 공격 뒤에 근접 캐릭터가 반격할 시간이 있는가.
- 둔화/흡입/밀치기가 겹쳐도 이동 입력과 대시로 벗어날 여지가 있는가.
- 소환·회복·장판 수에 상한이 있으며 지형과 함께 탈출로를 완전히 막지 않는가.
- 바이옴별 3–5마리 조합에서 동일한 공격 예고가 한꺼번에 몰리지 않는가.

## 결과물 검수 범위

- 4장 모두 직접 시각 검수: 바이옴 제목, 4종의 ID/이름, 기본·예고·공격 구획, 한국어 공격 요약과 서로 다른 실루엣 확인.
- 위 시트의 흡입 화살표를 입 안쪽 방향으로 수정하고 재검수.
- PNG 파일 열림·크기·원본 복사 일치와 문서 링크를 확인.
- 콘셉트 이미지와 문서만 제작했다. Unity 임포트 설정, 애니메이션 구현, 게임 내 시인성, 성능, 전투 밸런스는 이번 결과물의 검증 범위 밖이다.
